# よく使うwebsite | 発明 - GitHub

## 日本語

私はソフトウェアエンジニアとして働いています。

これなしには仕事ができない。

GitHubは開発者がコードを保存・共有・管理するプラットフォームで、世界中のエンジニアに使われています。

正直これを利用するにすごく驚いている。理系がやる仕事だと思っていたから。未経験からの転職成功。
私は経済学部で、最初営業の仕事をしていた。

GitHubにはカレンダーがあり、コードをpushすると、緑がつく。そしてそれがモチベーションになって、たくさんコードを書けます。

このwebsiteのおかげで、仕事がはかどっています。

## English

I'd like to talk about a website that I use very frequently, which is GitHub.

I work as a software engineer, and honestly, I can't really do my job without this website. GitHub is a platform where developers store, share and manage their code, and it's used by engineers all over the world.

What still surprises me is that I use this kind of website every day, because software engineering used to feel like something only science students or very technical people did. However, I successfully changed my career from a completely different background, and GitHub played a huge role in that process.

One feature I really like is the contribution calendar. Whenever I push my code, a green square appears on the calendar, and seeing it fill up actually motivates me a lot. It encourages me to write more code consistently, even on busy days.

All in all, thanks to this website, my work has become much more efficient, and it also keeps me motivated as a professional developer.
