This contract is consumed by the build pipeline (`src/build/`), the browser app (`src/app/`), and shared modules (`src/shared/`).

## Types (src/shared/types.ts)

```ts
export interface Segment {
  /** e.g. "Q1. Do you work or are you a student?" or "English" */
  label: string;
  /** Clean plain-text English content, paragraphs separated by \n\n */
  text: string;
  /**
   * Clean plain-text Japanese translation (from the source `日本語` section),
   * paragraphs separated by \n\n. Display-only — never spoken or highlighted.
   * Absent when the source has no Japanese section.
   */
  translation?: string;
}

export interface Lesson {
  /** Title from the first `# ...` heading of the MD file */
  title: string;
  /** Basename of the MD file, e.g. "01-studies-work.md" */
  file: string;
  segments: Segment[];
}

export interface Group {
  /** e.g. "Part 1", "Part 1 · special topics", "Part 2" */
  label: string;
  lessons: Lesson[];
}

declare global {
  interface Window {
    LESSONS: Group[];
  }
}
```

## Source MD conventions

- **Part 1 main files** (`part1/*.md`): contain multiple `## Q1. ...`, `## Q2. ...` blocks. Under each, there is a `### 日本語` and a `### English` subsection. Each Q becomes a Segment (`text` from English, `translation` from 日本語).
- **Part 1 special-topics** (`part1/special-topics/*.md`): same Q-block structure as above.
- **Part 2 files** (`part2/*.md`): contain a single `## 日本語` + `## English` section. One Segment per file.
- The `日本語` section is optional; when absent, `Segment.translation` is omitted. Only the English `text` is spoken/highlighted — the translation is display-only.

## Build output

### Data (`public/data.js`)

Assigns the parsed groups to `window.LESSONS` so that `index.html` can include it as a plain `<script>` and the app can read it synchronously.

```js
window.LESSONS = [ { label: "Part 1", lessons: [...] }, ... ];
```

### Audio (`public/audio/`)

Per-sentence MP3 files generated by edge-tts (Microsoft Edge Neural TTS, no API key required). UK accent, multiple voices — one folder per voice keyed by `voiceKey` (`sonia` = `en-GB-SoniaNeural` default, `ryan` = `en-GB-RyanNeural`, `libby` = `en-GB-LibbyNeural`). The voice list is the single source of truth in `src/shared/voices.ts`.

File naming: `public/audio/{voiceKey}/{groupIdx}_{lessonIdx}_{segmentIdx}_{sentenceIdx}.mp3`, with a per-sentence word-cue sidecar `…{sentenceIdx}.mp3.json` (`[{ part, start, end }]`, media-time ms) used for word-by-word highlighting.

Sentence and word counts are text-driven, so they are identical across voices; only audio and cue timings differ. The manifest (`public/audio-manifest.json`) therefore lists the voices once and shares the per-segment sentence counts across all of them:

```json
{
  "voices": [
    { "key": "sonia", "id": "en-GB-SoniaNeural", "label": "Sonia (UK, female)" },
    { "key": "ryan", "id": "en-GB-RyanNeural", "label": "Ryan (UK, male)" },
    { "key": "libby", "id": "en-GB-LibbyNeural", "label": "Libby (UK, female)" }
  ],
  "defaultVoice": "sonia",
  "segments": {
    "0_0_0": { "sentenceCount": 3 },
    "0_0_1": { "sentenceCount": 4 }
  }
}
```

## Build commands (package.json scripts)

| Command | Description |
|---------|-------------|
| `npm run build:data` | Parses markdown lessons → `public/data.js` |
| `npm run build:app` | Bundles `src/app/reader-app.ts` → `public/app.js` |
| `npm run build:audio` | Generates MP3 files via edge-tts (skips existing) |
| `npm run build:audio -- --force` | Regenerates all MP3 files |
| `npm run build` | `build:data` + `build:app` |
| `npm run dev` | `build` then serves `public/` on port 8080 |
| `npm run lint` | ESLint |
| `npm run format` | Prettier (write) |
| `npm run format:check` | Prettier (check only) |

## App features

1. Sidebar groups lessons by `Group.label`, with Part 1 / Part 2 tab switching.
2. Main panel renders each segment as a card with its own play button.
3. Player bar: play all / pause / stop / prev / next, speed slider (0.5 – 1.5x), voice picker (en-GB fallback voices).
4. **Audio playback**: pre-generated MP3 via `<audio>` element when available; falls back to Web Speech API.
5. Sentence-level highlighting with auto-scroll during playback.
6. Configurable inter-sentence pause (0 – 800ms, default 250ms).
7. Persist `{ rate, pauseMs, activeTab, voiceName }` to `localStorage`.
8. Keyboard shortcuts: Space (play/pause), S (stop), [ / ] (speed).

## UI aesthetic (落ち着ける / calm)

- Background `#F7F3EC`, surface `#FFFEFB`, border `#E6DED1`
- Text primary `#2F2A24`, secondary `#6B6258`
- Accent `#7B8B7A` (sage), accent-active `#5F6F5E`
- Highlight (reading) `#EADFC7`
- Body font: serif (Source Serif, Crimson Pro, fallback `Georgia, serif`)
- UI font: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- Rounded corners 10–14 px; shadows minimal (1px border + `0 1px 2px rgba(0,0,0,0.04)`)
- Plenty of whitespace; line-height 1.7 for reading text
- Respect `prefers-reduced-motion`; dark mode optional via `prefers-color-scheme: dark`

## Accessibility

- All interactive elements keyboard-accessible (Tab/Space/Enter)
- ARIA labels on play buttons; live region announces "Playing / Paused / Stopped"
- Color contrast >= 4.5:1 for body, >= 3:1 for large text
- Focus ring visible on all focusable elements
